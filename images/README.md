# Horse images

Put one image per horse here, named by horse number:

- `horse1.png` (1. 번개)
- `horse2.png` (2. 꾸준이)
- `horse3.png` (3. 럭키)

Supported formats: `.png`, `.gif` (animated GIFs play), `.jpg`.
Images are scaled to 52px height. Transparent PNGs facing right look best.
If an image is missing, a numbered circle is drawn instead.

Run the game from the project root (`./run.sh`, or IntelliJ with the working directory set to the project root) so the `images/` folder is found.
